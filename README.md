# Algoritmos e Programação de Computadores II

Códigos em C feitos nas aulas e atividades práticas da disciplina **APC II** (IESB, 2025).

## Conteúdo
| Pasta / arquivo | O que tem |
|---|---|
| `práticas/` | Atividades: conjectura de Goldbach, números perfeitos, quiz |
| `práticas/estudos/` | Estudos de ponteiros |
| `teste*.c`, `rascunho.c` | Exercícios feitos em aula |

## Como compilar
```bash
gcc práticas/perfeito.c -o perfeito
./perfeito
```
